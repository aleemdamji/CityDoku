1 · Puzzle quality scoring

Seeded candidate generation, answer counts for each square, diversity and balance penalties, and a release-style pass/fail gate.

2 · Interactive first-game tutorial

A three-step, non-competitive learning flow. No login, saved streak, or analytics.

3 · Post-game discovery

Shows overlooked valid answers for the currently evaluated puzzle. Facts come from the demonstration data, not a generative service.

4 · Automated quality checks

Validate dataset records, clue definitions and pairwise answer coverage. Export a JSON report or run the command-line test suite included in the zip.
